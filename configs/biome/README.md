# @myorg/biome

Linting and formatting for the whole monorepo, from a single shared config.

## What it provides

- `@biomejs/biome` as a shared workspace dependency
- `biome.json` — one shared config; there is **no root-level `biome.json`**
- `mbiome` — a bin that resolves Biome and passes `--config-path=<configs/biome>` for you

> [!IMPORTANT]
> Biome is the only lint and format tool. ESLint, Prettier and `lint-staged` are not used anywhere.

### Config highlights

| Setting | Value |
| :--- | :--- |
| Lint | `recommended` preset plus the `style` and `correctness` groups |
| Format | 2-space indent, 100 columns, double quotes, semicolons, trailing commas |
| Assist | Import organizing on |
| Ignores | `node_modules`, `dist`, `.turbo`, `coverage`, `test-results`, `.pages`, `uno.css` |

## Usage

```bash
bun run check        # lint + format check, writes nothing
bun run check:fix    # auto-fix what can be fixed
mbiome check --write # direct bin, same config
```

## Pre-commit

The Lefthook pre-commit hook runs `mbiome check --write {staged_files}` automatically, so committed code is always formatted. The hook lives in `configs/lefthook/lefthook.yml`; the root `lefthook.yml` is generated by `msetup`.

## Package boundaries

`noRestrictedImports` (error) blocks importing `bunup` directly — use `@myorg/bunup` — and blocks packages from importing `@myorg/example`. Apps may depend on packages; packages may not depend on apps.
