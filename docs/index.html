What is this?

This docs/ folder is template-only. It provides a static GitHub Pages site for the template repository itself (usage, scaffolding flow, config matrix). It is removed when you run bun create Archont561/ts-monorepo-template via configs/template self-destruct.

Scaffolding

bun create Archont561/ts-monorepo-template my-app
cd my-app
bun install
bun run dev        # http://localhost:3000
bun run test:template  # 81 tests covering every opt-in combo

Opt-ins: playwright (default true), codeql (default true), unocss, native (none/publish/docker), skills, devcontainer, pages, trivy, stale

How this docs site works

  • docs/index.html is static, no build step – served directly by Pages
  • .github/workflows/template-docs.yml deploys docs/ to Pages (template-only, removed on scaffold)
  • configs/template/package.json has extraRemovals: ["docs", ".github/workflows/template-docs.yml"] + filePatternsToRemove
  • Generated monorepos use configs/pages + pages.yml for apps/example, not this docs
