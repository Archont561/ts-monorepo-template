# Status

Numbers for this repository, collected at **build time** by
[`docs/status.data.ts`](https://github.com/Archont561/ts-monorepo-template/blob/main/docs/status.data.ts)
— a VitePress data loader that shells out to the same `m*` CLIs the CI uses
(`mcoverage summary --json`, `mpages base --json`).

Generated {{ when(data.generatedAt) }} from commit `{{ short(data.commit.sha) }}`<span v-if="data.commit.branch"> on `{{ data.commit.branch }}`</span>.

::: tip Freshness
The values below are as of the last docs deploy, not the last request. The CI
badges are live images served by GitHub; everything else refreshes whenever the
Template Docs workflow runs (pushes to `main` touching `docs/`, `packages/**`,
`apps/**`, `README.md`, `AGENTS.md` or `package.json`).
:::
